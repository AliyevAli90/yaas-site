# YAAS - Landing Page

Bu repository YAAS için SEO/landing içeriği barındırır. "YAAS" araması için optimize edilmiştir.

Deploy (örnek):
1. Vercel hesabınıza giriş yapın.
2. "Import Project" -> GitHub'dan `AliyevAli90/yaas-site` seçin.
3. Deploy yapılınca sayfa Vercel URL'sinde yayınlanır. Google Search Console'a publish edilen URL'i ekleyin ve sitemap.xml gönderin.

Varsa isteklerinizi burada bildirin.
